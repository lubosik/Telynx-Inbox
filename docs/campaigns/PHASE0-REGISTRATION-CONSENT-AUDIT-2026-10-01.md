## What was built, with no send capability

- Connector 0.4.1 adds `POST /wp-json/luko/v1/consent-audit`, protected by the existing HMAC timestamp, replay and rate checks. It accepts only 1–200 explicit WordPress user IDs and returns per-user consent verification, current resolved phone and source evidence where verified. It does not write user metadata, emit connector events or send a message.
- `scripts/audit-vici-registration-consent.js` reads the private cohort CSV and current LUKO consent/eligibility; after 0.4.1 is active, it also compares WordPress source evidence. Standard output is aggregate-only. An optional per-user CSV is written mode `0600` and refuses to overwrite an existing file.
- `scripts/audit-vici-first-purchase-baseline.js` rereads paid WooCommerce orders against the fixed nonbuyer cohort to detect first-purchase exits without sending or writing data.
- Focused cart/connector and new audit tests: **36 passed, 0 failed**. ZIP structure and integrity were checked. PHP CLI is unavailable on this Mac, so this local run did not include `php -l`; the installed WordPress route successfully answered the signed 195-user audit.
